# Queueless

**Queueless** is a real-time digital queue management system that helps users join, track, and manage queues without unnecessary physical waiting.

### Tech Stack

* **Frontend:** React, Vite, React Router, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB, Mongoose
* **Real-Time:** Socket.IO
* **Authentication:** JWT

### Key Features

* Digital queue management
* Real-time queue updates
* Token-based queue system
* User authentication
* Admin queue management
